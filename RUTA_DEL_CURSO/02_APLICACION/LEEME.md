# 02 — Aplicación

El código de la aplicación C# está **en la raíz de este repositorio** (no en un ZIP):

- `Program.cs`, `Controllers/`, `Views/`, `Models/`, `Data/`, `Services/` → tienda web ASP.NET Core MVC
- `Worker/` → importador de catálogo CSV (local o S3)
- `examples/products.csv` → CSV de ejemplo

Para instalar las herramientas y ejecutarla, sigue [CONFIGURACION_VSCODE.md](../../CONFIGURACION_VSCODE.md) y la sección 4 de [MEMORIA_DESPLIEGUE.md](../../MEMORIA_DESPLIEGUE.md).
